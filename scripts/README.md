# Scripts do projeto

Os scripts Python estão organizados por nomenclatura, mantendo todos os arquivos no diretório `scripts/`.

O padrão adotado é:

`M<Milestone>_I<Issue>_<descricao>.py`

Exemplo:

`M4_I24_tratar_ausentes_especiais.py`

Onde:

* `M4` identifica o Milestone 4;
* `I24` identifica a Issue #24;
* o restante do nome descreve a finalidade do script.

Uma mesma issue pode possuir mais de um script quando houver etapas distintas de análise, investigação, tratamento ou validação.

Issues exclusivamente documentais podem não possuir scripts associados.

Esse padrão permite relacionar rapidamente o código-fonte às fases e tarefas registradas no GitHub Project.
